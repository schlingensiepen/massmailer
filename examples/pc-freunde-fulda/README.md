# Example: PC-Freunde-Fulda

A fictional club used to demonstrate letterhead, template and recipient
list. All names and addresses are made up (`example.org`).

```sh
massmailer render -c mailing.example.json
massmailer send --dry-run -c account.example.json -c mailing.example.json
```
